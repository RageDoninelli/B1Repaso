V.I.V.A. B1 — Exam Trainer

Upload ALL files in this folder to the ROOT of a GitHub Pages repository. Enable Pages: Settings > Pages > Deploy from branch > main / root. Open the published URL in Chrome on Android and choose Install app / Add to Home Screen.

Includes 12 grammar topics, 120 original questions, randomized multiple choice, written responses, 36-question mock exams, offline caching, local progress.

IMPORTANT: Scores are saved only on each student device, not submitted to a teacher. The mock exam is formative practice, not a secure official exam. Written answers are automatically checked against a single model response; equivalent phrasings may be marked incorrect.

Based on the 12 grammar topics shown in the teacher-provided reference screenshots. Student Book and Workbook PDFs were received, but their scanned pages do not provide reliably extractable text; no claim is made of a full page-by-page exercise mapping. All included exercises are original, not reproduced from textbooks.
